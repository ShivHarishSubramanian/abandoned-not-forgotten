2) PROJECT SUMMARY (350+ words — paste into summary field)
------------------------------------------------------------
"Abandoned but not Forgotten" is an immersive scrollytelling website that
gives a voice to the machines humanity left behind on the Moon and Mars —
landers, rovers, instruments, even golf balls. Every mission to another world
has ended with hardware still standing on foreign soil, yet most people never
learn their names or what they accomplished. This project turns those silent
artifacts into storytellers.

Visitors land on a starfield hero, then explore an interactive Moon/Mars map
with clickable pins at approximate landing sites. Sixteen artifact cards —
from the Apollo 11 descent stage and laser retroreflector to the Spirit and
Opportunity rovers and the Ingenuity helicopter — each tell a first-person
story built from real mission facts, with key facts, a last-signal timestamp,
and links back to NASA sources. Stories can be read aloud via the browser's
speech engine. A filterable "Then vs. Now" timeline spans 1967 to 2024, a
"Why it matters" section explores space heritage, site preservation, debris,
and planetary protection, and visitors can leave one-line epitaphs on a
memorial wall held in memory only — no accounts, no tracking, nothing stored.
A six-question quiz generated live from the dataset rounds out the experience.

The site is pure HTML, CSS, and vanilla JavaScript — no frameworks, no
backend, no API keys — so it deploys anywhere and works offline with embedded
fallback data and original SVG illustrations. At runtime it queries the
public NASA Image and Video Library API for each artifact, displaying
credited imagery with links to the asset pages and graceful fallback when
offline.

Why it matters: it makes space exploration emotional and memorable for
students and the public, builds awareness of off-world heritage sites at a
moment when crewed return missions are being planned, and models responsible
exploration — asking what we leave behind, and who decides. It addresses the
challenge by combining real NASA data with human-centered storytelling in a
fully accessible, zero-infrastructure package suitable for classrooms,
museums, and public events.

3) PROJECT DETAILS (paste into "Project Details" field)
------------------------------------------------------------
WHAT IT DOES: A single-page scrollytelling experience. An interactive
Moon/Mars map (canvas-drawn discs, clickable pins at approximate landing
sites) leads into 16 first-person artifact stories drawn from
"data/artifacts.json" — each with mission, year, location, status, what was
left behind, an 80–140 word emotional story, key facts, last signal/activity,
and a source note for verification. Additional features: Then-vs-Now
timeline filterable by body; "Why it matters" section on heritage,
preservation, debris, and planetary protection; Web Speech API read-aloud;
in-memory memorial wall for one-line tributes (length and content filtered,
nothing persisted); quiz generated from the dataset.

HOW IT WORKS: Plain HTML5/CSS3/vanilla JS, no build step. app.js fetches the
JSON, renders cards, draws the map, and queries the NASA Image and Video
Library API (images-api.nasa.gov/search, 6-second timeout, in-memory cache).
On failure or offline it falls back to original SVG illustrations. Pin
coordinates are approximate equirectangular projections, labeled as such.

BENEFITS/IMPACT: Turns mission datasheets into emotional, memorable stories;
raises public awareness of off-world heritage and preservation debates;
models responsible data use (public APIs, attribution, graceful degradation);
fully offline-capable, accessible (semantic HTML, keyboard nav, reduced
motion), privacy-first.

TOOLS: Hand-written HTML, CSS (custom properties, responsive grid), vanilla
JavaScript (ES2020), Canvas 2D, Web Speech API, NASA public APIs. Developed
with AI-assisted drafting (disclosed in footer, README, and metadata) and
reviewed by the team. No copyrighted materials; all illustrations are
original SVG or credited NASA public-domain imagery.
